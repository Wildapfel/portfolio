	\section{Exp 02: Standard Scaling}
	
	Most of the models ROC-AUC of the GSE131599-test data set was mostly around 0.5 and is therefore not a valid model for a diagnostic classifier. I only found that the Naive Bayes model reached a ROC-AUC of 0.293. I investigated further, since on could flip the prediction logic here, to get a ROC-AUC of rougly 0.7.\\

	\section{Exp 04: RMA-train with Approximation-test}
	
		I found that 3 models (Logit, SVM-lnear, SVM-linear-weighted) had an ROC-AUC $>0.6$. Of course, this might not be the best performance, but considering that I approximated the RPM for the test data with a shift-scale-vector, working on noisy biological, older technology (microarray) and without batch correction, I would argue that this is the right direction to go. Those models could be a classifiers that actually learned biological signals and not just experimental artifacts ... \\

			\item The classifier performs perfect onto the train data (data seems to be separable with an hyperplane)

			\item But using the Youden's statistic threshold, yield a reasonable trainining classification, and would align with the performance of the GSE13159-test 
			\item So this model and this scaling seems to produce trustworthy predictions
			\item I would next inspect the GSE16355-test performance, 
		\end{itemize}
				
		\begin{center}
			\begin{tabular}{c}
				GSE16455-test SVM-linear Raw-Probabilities for samples \\
				\includegraphics[scale=0.7]{"./images/04_bg_corrected_train_dqn_ext_test_scaled/prob_svm-linear_f1_test2.png"}

		\begin{itemize}
			\item I investigate the threshold from the Youden’s J statistic and found that it is: $0.824$
			\item This would mean, considering this threhsold, that 7 / 17 would be classified correctly
			\item Considering the default threshold of 0.5, i would get 10 / 17 correct, but at that threshold the GSE13159-test performance would predict CLL classes worse. 
		\end{itemize}
		
		\textbf{Conclusion}
		\begin{itemize}
			\item I would argue that the SVM-linear onto the approxiamted scaling truely learns biolgical signal from this inehretly noise data 
			\item I can truely ee that the shift-scaled approxiamtion of the RMA seems to work and performs better then just a standard or rbust scaling 
		\end{itemize}
